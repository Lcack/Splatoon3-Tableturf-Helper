## 数值编码

卡牌：

```text
0 = 空
1 = 普通墨迹
2 = 特殊墨迹
```

场地：

```text
1  = 空地，可涂
2  = A 方预涂普通墨迹
4  = A 方特殊点
8  = B 方预涂普通墨迹
16 = B 方特殊点
32 = 中立/虚空，不可涂
64 = 墙，不可涂
```

A 方对应当前玩家，B 方对应 NPC。

规范矩阵采用从上到下、从左到右的零基坐标 `(row, col)`。从下往上计数时：

```text
内部 row = 总行数 - 从下往上行号
内部 col = 从左往右列号 - 1
```
