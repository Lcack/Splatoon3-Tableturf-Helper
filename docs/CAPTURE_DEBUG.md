# 采集卡诊断

以下命令均在项目根目录执行，`python` 指已安装本项目的解释器。

## 启动

```powershell
python -m tableturf_rebuild capture-debug
```

默认配置：

```text
后端：DSHOW
设备索引：0
分辨率：1920x1080
请求 FPS：60
```

已有标定使用 `Hagibis` 采集卡。设备索引由当前机器决定；如果索引 0 显示的是笔记本摄像头，可以依次测试索引 1、2。

## 检查项目

- 能否持续显示 Switch 画面。
- 实际分辨率是否为 1920×1080。
- 实测采集 FPS。
- 画面是否出现超过 2 秒的断流。
- 颜色、黑边、缩放比例和延迟是否正常。
- 左右声道不参与本轮画面检查。

## 调试功能

- 开始采集和停止。
- 开始录像和停止录像。
- 冻结当前画面，便于检查单帧。
- 冻结当前帧并打开状态标注窗口。
- 状态栏显示实际分辨率、实测 FPS 和最新帧延迟。

## 状态标注

点击“标注截图”后会冻结当前帧并打开标注窗口：

- 填写画面名称。
- 填写画面说明、关注点和当前可执行操作。
- 填写操作后进入的下一个状态。
- 使用椭圆圈选、矩形框选或箭头指出界面元素。
- 支持红色、黄色、青色标注。
- 支持撤销和清空。

每次点击“标注截图”可选择当前实时帧，也可先冻结再标注。

标注文件按会话保存：

```text
artifacts/state_capture/run-YYYYMMDD-HHMMSS/
├─ 001_state_name.png
├─ 001_state_name.annotated.png
├─ 001_state_name.json
└─ annotations.jsonl
```

原图、带标注图和结构化说明会同时保存，用于状态识别、ROI 标定和离线回归测试。

## 视频录制与审阅

采集窗口中的“开始录像”会录制原始采集帧，默认按 30 FPS 保存到当前状态
会话目录。优先尝试 MP4，编码器不可用时自动回退为 MJPEG AVI。

打开视频审阅窗口：

```powershell
python -m tableturf_rebuild video-review --video artifacts\state_capture\run-示例\session-示例.mp4
```

也可以不指定视频，在窗口中点击“打开视频”。

审阅窗口支持：

- 播放、暂停。
- 0.25×、0.5×、1×、2×、4× 播放速度。
- 上一帧、下一帧。
- 时间轴拖动定位。
- 在任意暂停帧使用同一套命名、说明和圈画标注。

右侧“状态机观察”区域显示状态、置信度与识别信息；“分析覆盖”控制画面叠加。
误判帧可通过“修正状态”保存人工模板，详见 [STATE_MACHINE](STATE_MACHINE.md)。
