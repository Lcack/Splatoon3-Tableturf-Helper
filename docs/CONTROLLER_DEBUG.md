# EasyCon 控制器调试

以下命令均在项目根目录执行，`python` 指已安装本项目的解释器。

## 安装控制器依赖

```powershell
python -m pip install -e ".[controller]"
```

当前项目使用 EasyCon ESP32-S3，协议参数为：

- 115200 baud
- 8N1
- 7-bit 控制器报告打包
- 握手：`A5 A5 81 -> 80`
- 控制器状态报告：单向写入，不等待每条报告的 ACK

EasyCon 只有握手、脚本控制等命令使用应答。控制器状态报告没有逐包 ACK，
因此界面不应把报告后的 `0x00` 当成拒绝。

## 启动调试界面

```powershell
python -m tableturf_rebuild controller-debug
```

界面包含：

- 串口刷新、EasyCon/Dummy 模式和连接状态。
- 十字键上下左右。
- A、B、X、Y。
- L、R、ZL、ZR。
- Plus、Minus、Capture、Home。
- 左右摇杆按下。
- `L + R` 组合键。
- `ZL + ZR` 组合键。
- 左右虚拟摇杆。
- 释放全部和摇杆归中。
- 协议错误日志。

数字键使用鼠标按下、松开释放的瞬时模式。组合键使用单独的按住按钮；
也可以在按住多个数字键后测试组合。

面板布局为两行三列：上排左右为双摇杆，下排左右为十字键和 ABXY，中间
跨两行区域依次放置扳机、肩键、截图/Home、Minus/Plus，第五行为
“回中”和“粘滞键”。L3 和 R3 分别位于左、右摇杆面板内。

- “回中”会释放全部数字键并将左右摇杆归零。
- “粘滞键”是全局模式开关。开启后，单击键或组合键会保持按下，直到再次
  单击同一键；关闭粘滞模式会自动执行回中，防止按钮卡住。

虚拟摇杆在拖动时发送轴值。默认在鼠标释放后自动归中；取消勾选
“松开鼠标后归中”后，可以分别固定左右摇杆，再测试双摇杆组合。

## 实机检查顺序

1. 先使用 Dummy 模式检查界面和按钮状态。
2. 切换到 EasyCon，刷新串口并连接 ESP32-S3。
3. 确认界面显示连接成功。
4. 在 Switch 菜单中逐项测试十字键、ABXY、肩键、扳机和系统键。
5. 分别测试左右摇杆的上下左右、斜方向和回中。
6. 同时测试“按键 + 摇杆”组合。
7. 拔掉 USB 串口，确认界面和日志能显示发送失败。
8. 关闭窗口时确认释放全部输入并让摇杆归中。

Home 和截图会触发 Switch 系统行为，测试前应退出关键游戏界面。
