# 继续对战弹窗文本

`prompt_text.npz` 只包含三个灰度文字裁片，不包含整图背景、玩家名片、NPC 或棋盘。

来源为本地实时采集 `artifacts/diagnostics/win-replay-stall-140226/capture.jpg`，1920 × 1080，2026-10-30 胜利后显示的继续对战弹窗。坐标为左、上、右、下：

| 键 | 原文 | 坐标 |
| --- | --- | --- |
| title | 要继续对战吗？ | 846, 490, 1076, 542 |
| cancel | 取消 | 765, 785, 821, 826 |
| continue | 继续！ | 1107, 778, 1176, 819 |

识别器要求标题及左右按钮文字均匹配。按钮允许明暗极性反转，兼容焦点切换；按钮颜色不能代替文字证据，也不用于推断当前焦点。标题保持白字正相关，并拒绝暗帧。搜索窗口及输入坐标按 16:9 画面缩放；实测覆盖 360p 至 2160p。

验证样本包括相同 NPC 失败后的重赛页和旧标注集的水母重赛页，避免把本次胜利背景作为识别依据。
